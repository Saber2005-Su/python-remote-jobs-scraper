# python-remote-jobs-scraper
Remote Jobs Scraper (Python + Requests)
Project Overview

This project is a simple Python-based web scraping tool that collects remote job listings from a public API and saves them into a CSV file.

It extracts structured job data for analysis and portfolio use.

Tech Stack
Python
Requests
CSV module
What This Script Does
Fetches remote job data from API
Parses JSON response
Extracts job details
Saves data into a CSV file
Output Fields

The generated CSV contains:

Position
Company
Location
Apply URL
Date
Tags Count
How to Run
1. Install dependency
pip install requests
2. Run script
python script.py
3. Output

A file will be created:

all_remote_jobs.csv
